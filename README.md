# DFG Forms in LaTeX

This repository contains LaTeX implementations of selected **DFG (Deutsche Forschungsgemeinschaft)** forms. These templates are designed to support researchers who wish to prepare DFG proposals or reports using LaTeX. This can be particularly useful when collaborating on documents through platforms like **Overleaf**, **Git**, or other version-controlled environments.

The goal is to offer clean, editable, and reusable LaTeX versions of standard DFG forms that closely follow the original formatting, while allowing full control over styling and content for scientific and administrative purposes.

> **Disclaimer:** These templates are provided *without any guarantee of completeness or correctness*. They are intended solely as a starting point for drafting your application or report. **Always cross-check with the official DFG forms** to ensure compliance before submission.
